# 數字記憶挑戰 Memory Maths

[直接玩遊戲](https://angusma0711.github.io/memory-maths/)

教師主持的數字記憶及四則運算遊戲，使用繁體中文介面。無需登入、安裝、後端或麥克風，不收集學生資料。

## 玩法

1. 選擇 **3×3、4×4 或 5×5** 網格，並從加、減、乘、除中多選 **1–4 種運算**（至少保留一種）。
2. 設定 **5–300 秒**的整數記憶時間，預設 30 秒；每回合題數可設定為 **1–30 題**，預設 5 題。
3. 設定卡片數字的最小值及最大值（**0–99 的整數**，最小值須小於最大值，預設 1–9）。學生記住數字與英文字母的位置配對。
4. 時間到後數字隱藏，字母及位置保留，顯示例如 **□＋□＝12**。
5. 學生口述兩張卡的字母，教師依次選卡，再按「檢查答案」。
6. 答錯可重試，數字繼續隱藏；答對只揭示所選兩張卡；按「洗牌並記憶下一題」後，同一組數字會重新洗牌、全部顯示，並重新開始完整記憶倒數。英文字母固定在原來位置，數字重新分配至卡位；倒數結束才隱藏數字及顯示下一條算式。
7. 每個新回合會重新隨機產生及排列數字，重新顯示牌面並開始記憶倒數。同一回合使用同一組數字，每題之間重新洗牌；最後一題後直接結算並顯示全部數字，不再倒數。教師亦可按「結束並揭示」提前結束，操作前會要求確認。

接受所有符合算式的組合。每題必須使用兩張不同的卡。減法與除法按選取次序計算；減法只出正整數答案，除法只出整除題，且除數不能為 0；0 可作被除數，加法、乘法及除法可出現答案 0。卡片數字可以重複，作答不限時。牌面保證有所選運算需要的有效配對；若範圍內沒有兩個不同數值能整除，會提供同值的兩張不同卡（例如 50÷50＝1）。「再玩一回合」會沿用目前的數字範圍、記憶時間、題數及其他設定。題目會平均分配至所選的運算種類；題數不少於所選種類數時，每種均會出現。相同運算的所有可用答案用完後，才會重複題目。

## 本機執行

在專案資料夾執行：

```sh
python3 -m http.server 4173
```

開啟 http://localhost:4173。JavaScript modules 需要 HTTP server，不能直接開啟 index.html。

## 驗證

使用 Node.js 20 或更新版本：

```sh
npm test
```

測試涵蓋所有網格和運算、題目可解性、不同正確組合、兩張不同卡片的限制，以及減法與除法的次序。時間輸入限制、倒數隱藏及中文介面另外透過瀏覽器檢查。

網站為純靜態檔案，GitHub Pages 直接從 main 分支根目錄發佈，無需 build 或第三方 JavaScript 套件。

## 課堂使用

初次可用 3×3、加法及 30 秒。答錯可能涉及記憶或運算，本遊戲適合作練習，並非診斷 assessment。可使用全螢幕功能投影。

## Firebase 多人搶答

首頁可選「單人模式」或「多人搶答」。房主建立房間後，其他玩家掃描 QR Code 或手動輸入房間代碼，並在房主開始前加入。每場固定 3×3、3 題。每題記憶 15 秒，接着有 30 秒作答。Firebase Realtime Database 只接受第一個合資格的正確答案。每題後由房主洗牌並開始下一題。全場最高分勝出，同分並列。

### 本機試玩

安裝 Firebase CLI 和 Java，然後在此資料夾的兩個終端機分別執行：

```sh
firebase emulators:start --project demo-memory-maths --only auth,database
```

```sh
npm run dev
```

以兩個獨立瀏覽器工作階段開啟 http://localhost:4173/pvp.html，例如一般視窗與無痕視窗各一個。本機預設使用 Auth 和 Realtime Database 模擬器。本機 QR Code 指向目前預覽網址，請在同一部電腦輸入房間代碼測試。跨裝置掃描須先部署到可連線的網站。

### 跨裝置試玩

正式版使用 `memory-maths-angusma` 專用 Firebase 專案，Firebase Authentication 採匿名登入，Realtime Database 位於新加坡。GitHub Pages 上的房間 QR Code 指向公開 HTTPS 網址。應用程式不設房間人數上限，Firebase Spark 方案在整個資料庫同時最多支援 100 個連線。

資料庫規則的維護指令：

```sh
firebase deploy --only database --project memory-maths-angusma
```

房間在第一題開始後停止接受新玩家，已加入的玩家可用同一瀏覽器工作階段重連。房間兩小時後停止存取，到期資料仍需由專案管理員清理。牌面及題目會同步到參與者的瀏覽器，熟悉開發者工具的玩家可以查看它們。
